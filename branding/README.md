# Branding

Boot screens for the device's 240x296 portrait LCD, generated by `boot_screens.py` (run with the
project venv: `tools/venv/Scripts/python branding/boot_screens.py`). `out/sheet.png` shows each
design next to a simulation of the washed-out panel (RGB565, lifted blacks, low contrast).

Where they go on the device:
- `startup.png` (rootfs `Resources/`, the launcher's first screen; Tonium's is a colour ring), the
  natural slot for `ring.png`. Changing it means rebuilding the cramfs rootfs (flash write; DFU
  recovery available).
- `boot.png` (`bin/resources/symbols/` inside the `.pfw` system image; Tonium's four-dot logo),
  the natural slot for `heartbeat.png`. Changing it only needs a rebuilt `.pfw`.
- The very first logo is compiled into the kernel (`CONFIG_LOGO_TONIUM_CLUT224`, a 224-colour
  image), so changing it needs a kernel rebuild from Tonium's GPL source.
