# The settings menu

## Open the menu

Press the settings button with a track loaded. Edit settings in the app on the [Device page](device-page.md): **Device settings**, and **Settings presets** to save and re-apply them. A new firmware number resets all settings to default: see [Installing firmware with the app](install-firmware.md).

## First screen and Playback

| Setting | Options | Default | What it does |
|---|---|---|---|
| Shutdown | action | | Switches the Pacemaker off |
| Volume | | | Line-out volume of the mix |
| Restore all | action | | Resets preferences. Tracks and mixes are kept |
| Play mode / Mix mode | action | | Simple player or two-channel mixer. Play mode uses less power |
| Mix save | On, Off | Off | Records your mix: see [Recording mixes and making cases](pm-recording.md) |
| Halt | Continue, Save, Lock, New | | Ends or continues a recording |
| Lock, Unlock | action | | Locks the Pacemaker |
| Repeat (Play mode) | Off, One, All | Off | Repeat |
| Shuffle (Play mode) | On, Off | Off | Shuffle |

## Settings, Mix control

| Setting | Options | Default | What it does |
|---|---|---|---|
| Autocue | On, Off | On | Cues a track at its first beat on load |
| Fixed loop length | Off, 1/64 to 4 | Off | Loop length: see [Cues, loops and reverse](pm-cues-loops.md) |
| Snap loops | On, Off | On | |
| Beat jump length | 1/16 to 8 | 1/2 | |
| Loop travel | On, Off | On | |
| Time stretch | On, Off | On | Keeps pitch when tempo changes |
| Vinyl mode | On, Off | Off | Called "Vinyl pause" in the manual |
| Effect x-fader | Off, Bass, Filter | Off | Folds an effect into the crossfader |
| Phones x-fader | Relative, Normal | Normal | How the headphone crossfader shows |
| Beat graph | Off, On | On | |
| Lineout warning | On, Off | On | |

| Setting | Options | Default | What it does |
|---|---|---|---|
| Normalize | On, Off | On | Evens out loudness |
| Phones, Range | Low imp, High imp | Low imp | Headphone impedance. Keep volume low |
| Phones, Volume limit | | | Not editable in the app |
| Phones EQ | Treble, Mid, Bass | 0 | Headphone tone |
| Lineout, Volume and EQ | | | Not editable in the app |
| Digital (Play mode) | On, Off | Off | Digital output |

## Settings, Configure

| Setting | Options | Default | What it does |
|---|---|---|---|
| Track list filters | Mix, Case, Album, Artist, Genre, Label, BPM, Key, Added, Rating, Type, Bitrate, Year, Remix | On: Mix, Case, Album, Artist, Genre, BPM | Filters the track list offers |
| Track list | Linked, Split | Split | One shared list, or one per channel |
| Track time, Display | Left, Played | | Time left or time played |
| End alert (Mix mode) | On, Off | On | Warns near the end of a track |
| FX layout, Edit | 8 slots (north, east, south, west, each also with the P-switch up) | EQ and gain without the P-switch, effects with it | Function of each pad slot: see [Effects, EQ and the Vocal filter](pm-effects.md) |
| FX layout, Restore | action | | Restores the default layout |
| Language | English, Korean, Japanese | English | Menu language |

## About

Shows Status (battery percent, space, number of mixes and tracks), Version (model, firmware, software, support) and **Legal notice**.

## Track list menu

The settings button in the track list opens **Add to case**, **Add all to case** and **Remove**: see [Recording mixes and making cases](pm-recording.md).
