# Getting started

## Library types

| Type | What it is |
|---|---|
| Library on this computer | Folder with tracks, mixes and cases. Works without a Pacemaker. |
| Pacemaker | The drive or card holding the library the unit plays from. |

Switch with the library picker at the top of the window. Free space applies to a Pacemaker only. Sync needs a library on this computer.

## Welcome screen

| Button | What it does |
|---|---|
| Start a library on this computer | Creates a Pacemaker Revival folder in Music. The location can be changed first. |
| Copy my Pacemaker's library to this computer | Shown when a Pacemaker is connected. Lists what will be copied, then copies. |
| Open a Pacemaker | Connect over USB, then press Rescan. A folder containing `.Pacemaker` also opens. |

If the library drive is missing, connect it and press Rescan. A connected Pacemaker also gets a small prompt with **Open it**: [Libraries](libraries.md#pacemaker-connected).

## Add tracks

1. Press **Add tracks...** or drop files or folders anywhere in the window.
2. Each file is analysed and added with its beat grid.

Lists from other software: [Import and export](import-export.md).
