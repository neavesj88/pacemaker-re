# The Settings page

Open **Settings** in the sidebar, under Tools. Pacemaker settings (backlight, effects layout) are on the Device page: [The settings menu](pm-settings-menu.md).

## Search settings

Matches title, help line, keywords and area. Matching help articles are listed under **Help**.

## Areas

| Area | Contents |
|---|---|
| Appearance | Interface size, error and "finished" message times, beat grid on the player, playhead smoothness, waveform colours |
| Library | Library location, Pacemaker connected prompt, energy source, metadata clean-up recipes, writing tags to files, Sync |
| Cases | Smart cases, case export, duplicate finder |
| Mixes | Auto transitions, snap and beat-align, following the playhead, tempo matching, mix audio export, track list and CUE sheet, set builder |
| Analysis | BPM range, background analysis, key detection, energy, sections, suspect beat grids, tempo tools, gap map |
| Import and export | Watch folders, request list matcher, printable setlist, VirtualDJ list export |
| History | Play log |
| Device | Safety (undo, restore, fix), finding missing audio, included firmware, free-space planner. Named Library tools while a library on this computer is open |
| Stems | Stem separation |
| About | Licences of included software |

## Pacemaker connected and included firmware

| Setting | Where | Default |
|---|---|---|
| **Ask to open a Pacemaker when one is connected** | Library | On |
| **Check for a connected Pacemaker every (s)** | Library | 3 (0 = off, up to 600) |
| **Offer the included firmware** | Device | On |

Checking only lists the drives; a Pacemaker is opened only when you click **Open it**: [Libraries](libraries.md#pacemaker-connected). The firmware setting: [Installing firmware with the app](install-firmware.md).

## Interface size

The slider sets the window size. Pick a smaller size if things do not fit. Shortcuts:

| Keys | Action |
|---|---|
| Ctrl and + | Larger |
| Ctrl and - | Smaller |
| Ctrl and 0 | Default |

## Playhead smoothness

| Option | Use |
|---|---|
| Up to 60 a second | Default |
| Up to 30 | Lower load on older computers or laptops on battery |
| Every screen refresh | Display rate |

## Waveform colours

| Option | Look |
|---|---|
| Matrix green, calm | Default. Three greens. |
| Neon | Pink, lilac and bright green. |

Applies to the player, track pictures and grid editor: [BPM, keys and waveforms](bpm-keys-waveforms.md).
