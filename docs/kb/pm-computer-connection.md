# Connecting to a computer

## Connect

The Pacemaker is a USB mass storage drive. Do not rename or move files in its hidden `.Pacemaker` folder.

1. If it is only charging, press the settings button to turn on the data connection.
2. In the app, press **Rescan**, then open it from the library picker: see [Getting started](getting-started.md).

## Disconnect safely

1. Use **Eject** on the Device page, or the Windows eject.
2. Wait for "Do not disconnect!" to clear on the Pacemaker's screen.
3. Unplug the cable.

Never unplug during a transfer.

## Copy music and playlists

| Method | What it does |
|---|---|
| [Sync](sync.md) | Copies tracks, mixes and cases both ways after a preview |
| [Libraries](libraries.md) | Copies by dragging |
| Tonium Editor | Installer is on the Pacemaker's drive. Drag tracks, cases and mixes into the Pacemaker pane. Deleting there deletes from the Pacemaker. Cases and mixes copy back to the Editor, tracks do not |

The Editor's update and community servers no longer work.

## Install firmware

Copy the firmware file into the `.Pacemaker` folder. It installs at the next start: see [Installing firmware with the app](install-firmware.md). Do not start the Pacemaker with USB connected while an update is waiting.

## Large transfers

For many gigabytes, use a PC card reader on the removable storage: see [Ways to install firmware](firmware-methods.md).
