# Duplicates

**Duplicates** (in the sidebar) finds copies of the same recording so you can keep one and merge the rest into it.

## Find copies

1. Tick one or more methods.
2. Press **Find duplicates**.

| Method | Matches |
|---|---|
| Same artist and title | Ignores case, punctuation and "feat.". About the same length |
| Same file size and length | Identical size and length |
| Sound check | Compares how tracks sound. Press **Fingerprint N tracks** first. Cancel keeps what is done |

**Settings** sets each method's strictness and which copy is suggested for keeping.

## Merge

1. Tick the groups to merge. Each group lists every difference between its copies.
2. Press **Review merge...**. The dialog lists every change.
3. Choose whether to remove the extra copies from the library, and separately whether to delete their files.
4. Confirm.

Cases, ratings and plays carry into the kept copy as set in [The Settings page](settings-page.md). A copy used by a mix stays in the library.
