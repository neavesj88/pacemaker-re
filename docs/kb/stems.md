# Stems

**Stems** (under Tools) splits tracks into a vocal (acapella) file and an instrumental file.

## Set up

In the **Model and engine** card, press **Review notice and download** for the model and the engine, and accept each licence notice. **Remove** deletes a downloaded part.

## Make stems

1. Choose tracks: tick them in the list, press **Choose N shown**, or use **the selected tracks in Tracks**.
2. Choose an output folder on this computer. Folders inside the library or the Pacemaker are refused.
3. Review the plan: every file to be made and every file to be replaced.
4. Start.

## Options

Settings, Stems:

- What the engine runs on.
- Output format and overlap.
- File name suffixes (for example "acapella" and "instrumental").
- Skip or replace existing files.
- Location of the model and the engine library.

## Results

The result card lists files made, failures and skips with reasons. To add the files to the library, review the list and confirm. They appear as ordinary tracks without tags.

For a vocal filter during mixing, see [Mix tools and audio export](mixes-tools-export.md).
