# Free space

**Free space** (under Tools) appears only while a Pacemaker is open. It nominates **candidates** to archive or remove, each with a reason, for example a track never played or one that repeats another track's audio. The target is a number of GB kept free, or the library fitting a card size you give.

## Free up space

1. Press **Scan again** if the card changed. The headline shows what the library takes and how much must be freed.
2. Review the list. **Tick suggested** ticks the nominated tracks, **Tick shown** ticks what the filter shows, **Untick all** clears. The footer shows the space freed.
3. Choose an action for the ticked tracks, then confirm.

## Actions

| Action | Effect |
|---|---|
| **Archive...** | Copies tracks to a new folder on this computer and verifies each copy. Tracks stay on the Pacemaker. Adding the files to a Pacemaker again restores them |
| **Remove...** | Takes tracks off the Pacemaker |
| **Archive and remove...** | Both |

A track in a mix can be archived but not removed. Back up the Pacemaker before removing: see [The Device page](device-page.md).

## Options

Settings, Device, **Free-space planner**: which candidate reasons are on, limits (for example tracks in no case or no mix), protected tracks (for example Favourites), list order, and where archives go.

For a bigger store instead, see [Upgrading the storage to a microSD card](storage-upgrade.md).
