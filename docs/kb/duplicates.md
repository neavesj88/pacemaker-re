# Duplicates

**Duplicates** (in the sidebar) finds tracks that are the same recording, so you can keep one and merge the rest into it. Finding changes nothing.

## Finding copies

Tick one or more ways to look, then press **Find duplicates**:

- **Same artist and title**, ignoring case, punctuation and "feat.", and about the same length.
- **Same file size and length.**
- **Sound check.** Compares how the tracks sound. Each candidate file is read once and the result is remembered, so a second search is quick. A progress bar shows the work; Cancel keeps what is done. Press **Fingerprint N tracks** to do the reading.

**Settings** says how strict each way is and which copy is suggested for keeping.

## Looking at a group

Each group of copies is a card that shows every difference between them (tags, length, bit rate, plays, cases and so on). Tick the groups you want to merge.

## Merging

Press **Review merge...**. A dialog names every change before anything is written. Removing the extra copies from the library and deleting their files are **separate choices**, so you can merge the details (cases, ratings, plays) into the copy you keep without losing any files. What a merge does with cases, ratings and plays is set in the duplicate finder settings.

A copy that a mix uses stays in the library and is listed in the dialog. See [The Settings page](settings-page.md) for the settings.
