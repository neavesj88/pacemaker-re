# Recording mixes and making cases

## Record a mix

1. Switch to Mix mode.
2. Open **Settings** and set **Mix save** to **On**.
3. Mix.
4. Set **Mix save** to **Off** and choose **Save**, **Discard** or **Cancel**.

**Mix save** is off after every start.

### Halt options

**Halt** offers **Continue**, **Save**, **Lock** and **New** (starts a new recording).

## Use recorded mixes

Import saved mixes from the Mixes page: see [Building a mix](mixes-building.md). Mixes sent from the Editor appear as track lists with each track's start as a cue point. Effect curves and automation are not played.

## Add tracks to a case

A case is the Pacemaker's playlist.

1. In the track list, select a track.
2. Press the settings button.
3. Choose **Add to case**, then **Create case** or **My cases**, and swipe right.

**Add all to case** adds every track in the filtered list. A new case is named "New Case" plus a counter. Adding a track twice creates a duplicate row.

## Remove a track from a case

1. In the track list, hold the P-switch up and filter by **Case**.
2. Select the case, then the track.
3. Press the settings button, choose **Remove** and confirm.

## Edit cases in the app

See [Cases and smart cases](cases.md). The app heart adds a track to a case named Favourites: [The Tracks view](tracks-view.md).
